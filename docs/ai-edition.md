# 酸橙 AI 扩展版

[源码与界面](https://github.com/2742360657/Lime/tree/extended/dev) · [测试版 APK](https://github.com/2742360657/Lime/releases/tag/ai-v1.3.0-alpha.1)

扩展版包含习惯、待办、备忘录，以及助手、附件、微信/QQ 前台收件和本地通知。模型和消息平台使用外部网络 API，需要在手机里配置自己的账号和密钥；不会捆绑密钥或部署服务器。

它是独立安装的测试版，包名 app.lime.personalassistant，名称“酸橙 AI”；本地版包名与数据不受影响，两版的备份格式不同，不自动互相导入。真实模型和渠道体验仍需用户按自己的服务验收；不要把截图或构建通过当成真实账号已经接通。

主线本地版继续维护；AI 版的变更与说明维护在 extended/dev，不混入 main。
