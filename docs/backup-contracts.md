# P5-04 本机完整数据包与恢复契约

日期：2026-10-10。手机独立模块，无服务器、云备份或新增账户。

## 格式与范围

ZIP使用Android系统[java.util.zip](https://developer.android.com/reference/java/util/zip/ZipInputStream)，不自写归档/压缩算法。固定manifest.json（lime-local-backup/version 2；兼容历史version 1）及blobs/<SHA256>.bin，目录名不直接用作目标路径。结合[官方路径穿越建议](https://developer.android.com/privacy-and-security/risks/zip-path-traversal)拒绝未知/重复条目、路径穿越、非法UTF-8、超限及hash不符。

覆盖普通SQLite数据：分类、日记/备忘录、待办、习惯/打卡、编辑草稿/冲突原文、显式记忆、活动、人格原文、聊天/请求、来源快照、建议/结果、操作回执、材料正文/原件/分析图片、提醒规则；历史来源摘录/恢复快照和模型名称使用明确local_meta白名单。以前完整恢复的冲突包作为不自动解压的原始ZIP一并携带，保持恢复副本可再导出。

不包含SecureStore/Key/微信token/媒体钥匙、Agent grants、系统通知实例、迁移内部标志、普通页面外观/头像设置、旧服务缓存、未处理Android分享队列及微信独立验证沙箱。材料选择草稿是授权状态，不自动恢复选中；原件与已保存正文仍保存。普通备份不调用模型，不将人格或用户内容发送网络。

上限：manifest 25MiB、普通原件/图片每件10MiB、整个压缩包及解压总量256MiB、最多1024条ZIP entries/50000行。超限/缺失原件停止导出，不生成声称完整的缺件包。包是明文私密文件，设置页提示包含聊天/人格/附件。完整备份与旧基础JSON兼容入口共存。

## 确定性恢复

先有界私密读取/验证格式与所有blob hash、字段及引用，再展示范围确认。取消不修改SQL。SQL写入和导入回执一次事务提交；文件先安装不可变副本，不覆盖原文件，数据库失败可能留下不可见孤立副本，但不留下半次业务恢复。程序重开/同包重试依据回执防重。

保持稳定ID、revision、原文和来源版本；相同ID/内容跳过。不同版本不覆盖、不自动改所有关联ID；冲突及依赖该冲突的对象不激活，完整输入ZIP保存在恢复副本并可导出核对，其余独立对象正常新增。UI显示新增/相同/冲突数量；没有权限恢复隐藏删除或永久清理。

恢复请求统一为restored只读历史，不可retry；pending建议也转为restored历史，不可接受；已提交结果/操作回执保留用于来源回看。Agent授权不导出/恢复，未完成请求不重放。提醒规则新增时disabled，系统实例不恢复；现有提醒设置/队列不改变。新增恢复待办的当前revision暂停自动到期提醒，用户编辑该待办后才重新按已有设置排程。人格新增时disabled，现有人格不覆盖。用户仍可在原设置页选择启用恢复的人格/规则。

关联校验区分当前实体与历史快照：习惯/打卡、活动/习惯和打卡、分类、会话/请求/消息/结果、建议及操作回执依赖明确对象；历史来源允许原实体已不存在，但保留原文快照，不能据此取得新的工具权限。不得执行包中任意SQL/路径/指令；所有表名/字段由源码白名单决定。

## 模块和集中验证

先实现固定schema/投影/安全恢复计划与事务，再实现系统ZIP边界、设置入口与隔离原生探针。开发中登记案例，阶段结束集中检查：全对象回环/跨目录路径改写、hash与引用拒绝、缺件/损坏/路径攻击/超限、重复/版本冲突及依赖隔离、事务失败、恢复历史不能执行、规则/人格停用、旧JSON兼容、手机原生ZIP/SQLite重开/零队列与普通记录摘要。人工系统保存/选择/取消另记结果。

正式微信接入时扩展为25类普通对象（新增local_weixin_items）。媒体能力字段导出为null，账号/游标/协议缓冲不导出；恢复未保存项为只读历史，保存项关联原件。详见[正式微信契约](weixin-intake-contracts.md)。
