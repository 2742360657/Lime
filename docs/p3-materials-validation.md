# P3 材料入口技术验收

日期：2026-10-09。范围为手机直接文件/图片、系统分享/打开、受限材料上下文与来源回看。微信/QQ及系统提醒仍为P4；没有新增产品服务器。人工体验与正式发布不与技术验收混为一项。

## 实现与数据边界

原件进入手机私有材料目录，新增两张local-only表，沿用既有数据库，不清数据。Native持久入站→SQLite回执→Native确认；内容SHA-256去重。选择草稿按会话保存，发送时固定来源版本与正文快照。解析更正/归档使旧建议失效，接受建议经过现有domain事务和回执。保存或接收不调用模型，仅选中后发送才提交该轮文本/图片；附件不能授权业务写入。

使用既有Expo文件组件、Android ContentResolver/Bitmap/PdfRenderer、AI SDK/DeepSeek provider，没有增加PDF引擎、OCR服务或第二套Agent框架。格式与限额见[材料契约](material-contracts.md)。Office仅保存，PDF文本提取要求Android35+；扫描页以有界图片供模型分析，不称为确定OCR原文。来源更正不改写原件，归档暂不物理回收。

## 修复与续测

恢复后发现Metro localhost优先绑定IPv6，模拟器默认IPv4主机地址不能加载；本任务启动Metro时指定IPv4 DNS优先，未修改系统DNS。材料入站监听增加重叠收件再排空处理，避免正在导入时新事件被忽略。文件选择器改为直接读取临时授权content URI，避免Expo预缓存整个超大文件，不删除外部原件。显示可信限额/副本丢失错误；来源实体暂不可读时仍显示已保存的正文快照。原生限制自有content provider读取，开发版只允许合成fixtures；探针临时库清理改用实际Android数据库目录。

UI验收发现开发包LogBox浮层会截获下方点击；脚本关闭可见调试警告后再定位，不屏蔽产品错误。材料提示移到导航栏上方，避免遮住底栏。启动与材料导入分别等待实际可见节点。选择器续跑修正目录节点等待；Android调试包在ADB注入含两个R的字符时触发RN重载，改用不触发快捷键的合成后缀。任务行点击是完成操作，来源测试改点该行“编辑待办”。这些定位/输入问题修正后从失败条目继续，没有重跑已通过云调用或清数据；最终脚本未再从全新数据完整起跑。

建议界面使用仅允许模拟器的合成聊天/建议样本，接受和来源读取走真实domain/数据库；不是模型在手机真实生成该建议。SDK图片与建议回路由自动化验证，真实视觉由独立Node生产运行时验证，证据不能合并成未经执行的手机云端全流程。原生探针使用独立随机合成库，界面脚本只允许模拟器；没有操作真人资料。

## 未测与发布限制

- 冷启动SEND_MULTIPLE、多选系统选择器完整组合与重叠收件高频压力；本批热多文件和其他系统入口已有证据，不能扩写为全部组合通过。
- 小米HyperOS的实际分享提供方、文件授权/过期、中文IME、相册和角色表达体验；当前没有真机连接。
- 完整手机真实Key多模态聊天，弱网/断网与停止组合；本批Node真实视觉与已有P2原生SDK合成流分别证明不同路径。
- 加密PDF、极端复杂PDF/图片、EXIF各方向实拍、磁盘耗尽、云文档提供方长时间阻塞与复制中强杀，尚无本批完整证据；代码失败保留原件不等于全部实测。
- 完整聊天/记忆/附件导出恢复及物理回收在P5；旧基础JSON不是完整材料备份。100项材料列表和轻量正文预览为本批范围，不提供全功能Office/PDF阅读器。
- 最终正式签名release、依赖风险处置及应用发布仍未完成；本地preview不是公开Release。
