# P2-B/C 本机助手契约

日期：2026-10-09。本批范围是直连文本聊天、可选人格、显式记忆、受限记录工具和持久化恢复；本契约最初限定P2；当前P3文件/图片与系统入口补充见[材料契约](material-contracts.md)。

- 使用固定版本AI SDK Core及DeepSeek provider处理流和有界工具循环，Expo fetch直接访问官方API；不引入代理服务器或自写模型协议。
- Key只存SecureStore。模型默认deepseek-flash。人格为用户选择的UTF-8 Markdown/文本文件，原文保存在应用私有SQLite；预览后显式保存/替换，可以停用或移除。不预置私人人格，未启用时使用中性助手。人格不是用户事实，不提供工具权限。
- 会话、消息、请求、建议与提交回执分别保存。整个应用共用一个执行器；停止保留已经提交的操作，重启将未结束请求标为中断，重试沿用请求及授权/操作ID。
- 应用从本轮用户直接输入创建有限授权，授权不由模型、历史消息或材料提供。仅无材料的明确新增待办、显式记忆、训练计划及唯一活动完成可获得一次命令授权；其余修改先生成可编辑建议。每种授权只能绑定一份命令，变更参数不再自动执行。歧义、否定和引用输入采用建议。
- 自动写入在domain边界检查持久化授权、请求、命令类型、目标和额度，提交与授权消耗同一事务。模型没有UI身份、SQL、文件删除、永久删除或授权工具。
- 本轮选中的日记/备忘录/附件合计最多4份，校验版本；工具只读取这些记录。普通保存不触发分析。记录正文只在当前请求的用户材料中提供，历史轮次不重新附带正文；来源变化会阻止新提交和建议接受。
- 上下文为当前人格、有限历史、显式记忆、未完成活动与当前材料。忘记记忆同时设置上下文边界，旧聊天仍可查看但不再自动参与后续模型上下文，避免旧事实自动复活。不是删除历史聊天。
- 业务结果以domain回执为准，建议不能显示成已保存。人工接受/编辑/拒绝发生在聊天；记录页面继续订阅同一数据库。
- 不自动把所有日记、习惯或附件发模型。普通记录导出暂未包含本批人格/会话/记忆，完整导出在P5；界面和文档须明确。

验收重点：人格取消/替换/停用/重启；Key不进入DB/日志；Hermes SDK实际流和工具兼容；停止/错误/重启/重试防重；跨会话完成一次打卡；材料指令不能升级授权；建议编辑后接受与版本冲突；忘记后的上下文不再含旧事实。阶段末集中运行，人工体验与真实API证据分别记录。
