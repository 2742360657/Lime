# 离线日用管理续开发

2026-10-11，从8ba35b1建立feat/p5-offline-daily-management。用户要求继续开发、真机未接入，测试留到后续统一做。本批不执行功能套件、云调用、APK构建或设备测试；实现与待验分别记录。

范围：显式个人记忆的字面搜索/种类筛选/稳定游标分页、手动新增/更正/忘记；助手查询旧记忆及截断说明；活动计划的离线创建、按状态查询、完成/取消和已关联打卡反馈。继续复用成熟备忘录编辑器和既有domain事务/回执，不新增数据库表、模型权限或后台。

读接口在同一事务中返回当前匹配总数、有限记录、剩余数量与下一页游标。个人记忆关键词只查询未忘记的key/content，LIKE通配符按字面转义；助手搜索不读取日记或未授权备忘录。活动按状态/标题或类型筛选，展示关联习惯及已有打卡状态，计划和打卡不混算。查询与翻页不写业务记录。

手动写入仍核对目标版本，回执在实际事务提交后展示。完成关联活动只生成一次习惯打卡；取消不打卡。失败保留输入，同一参数重试复用operationId，用户修改参数后创建新操作；重复点击以同步锁拦截。关闭/重开及快速切换查询不应用迟到结果。

记忆管理不需要模型Key。模型上下文仍有界；query_memories可按关键词和游标找到最近记录以外的显式记忆，不推断长期事实。忘记沿用上下文边界及内容清除；本批不改历史聊天保存或备份v3格式。
