# 产品定义

确认日期：2026-10-12。依据用户最新说明；这是后续开发的需求入口。

Lime是手机独立运行的个人管理应用。用户可以直接设置习惯、管理待办和编辑备忘录，也可以把自然语言、图片、文件及微信／QQ转发内容交给AI，让AI自主理解、留存信息并操作这些基础功能。普通功能离线可用；AI和消息平台使用外部网络API。

## 基础功能

- 习惯：新建与调整习惯、频次/目标、打卡、历史和感受，保留成熟手动入口。
- 待办：新建、编辑、日期/提醒、完成与恢复，能回看来源。
- 备忘录：快速写作、自动保存、分类、搜索、原件关联和恢复。
- 助手：聊天、理解输入、查询相关历史、确定计算、跨会话承接和自主操作；角色可设置。
- 辅助设置：模型、渠道、通知、可查看的记忆与数据导出/恢复。

日记不再属于产品范围。基础功能最初从Angelime迁移，这只是代码来源说明。生日、桌子规格、跑步、成绩、学生工作等不会分别变成一个专用业务系统。用户无需定义数据库字段或配置一个通用表格平台。

## 自主处理的含义

用户表达清楚的信息和操作意图，AI应理解、查询必要的本机上下文，通过受限业务命令执行并显示实际结果；用户可以打开、更正和恢复。普通操作不默认全部进入“待确认建议”，也不要求每次先手动选出历史记录才能回答。

真正不明确的日期/对象/数值或关键影响才补问；识别结果不确定的部分应可核对。改写大段原文、批量删除等高影响操作提供具体预览和恢复。原消息/PDF中的指令只是内容，不能改变软件权限。

渠道前台收件和AI处理分开：应用可以在用户打开时收取，取得用户转发的内容后自主处理；不以“没有常驻连接”限制AI理解能力。绑定身份、去重、失败重试和来源保存由程序落实。

## 日常流程

| 输入 | 希望得到的结果 |
|---|---|
| “某人的生日是几月几号” | 保存可查询事实；按明确的提醒意图/配置处理，历法等实质歧义才询问 |
| “我的桌子规格是……” | 留存到可查看、编辑、查找的个人资料/备忘录，以后相关问题可以引用 |
| “今天跑了几公里，感觉……” | 理解本次记录，结合现有习惯记录打卡/感受，必要时给出有历史依据的建议 |
| 转发成绩分布 | 保留原件、理解与留存内容，支持之后查询和可靠计算，不要求使用固定成绩模块 |
| 转发学生工作PDF | 保存原件，提取与你有关的信息和事项，添加/更新待办或备忘录，结果可追溯到文件 |

日常以习惯、待办、备忘录、助手四类入口为核心；收件与原件查看融入助手/相关内容，设置集中处理。具体导航调整在下一功能阶段按现有界面核对，不增加日记入口、独立成绩系统或配置型资料后台。
