# 数据与隐私

适用于 main 本地业务版 v1.3.0 及以后；extended/dev 有独立的外部模型/渠道能力，不适用本说明。v1.2.x 正式包未使用网络权限。

- 习惯、待办、备忘录、主题与本地资料保存在应用私有目录 `habit-checkin/data.json`，使用版本化 JSON；无登录、广告、统计 SDK 或远程业务 API，不上传这些内容。
- 软件更新通过 HTTPS 从 GitHub 的固定正式发布地址读取版本清单，下载适合设备架构的 APK；GitHub 及其下载 CDN 会像普通下载一样收到网络地址和请求信息。请求不附带账号、业务内容、设备唯一标识或认证令牌。
- 自动检查默认开启，在应用启动或返回前台时最多每天检查一次；可在设置关闭，手动检查与打开发布页仍可使用。没有定时后台服务，不自动下载。用户确认下载后，安装包存放于应用私有缓存，下载失败/取消后删除，重试时清理旧包；系统也可能回收缓存。
- 正式包使用 INTERNET 权限检查/下载更新，REQUEST_INSTALL_PACKAGES 仅在用户点击安装后打开系统安装流程。Android 8+ 首次安装需要允许“来自酸橙的安装”；不静默安装，也不自动打开权限页面。FileProvider 只共享更新缓存中的单个 APK 给系统安装器。
- 不使用 SYSTEM_ALERT_WINDOW 或旧 READ/WRITE_EXTERNAL_STORAGE 权限。开发调试包还可能联网连接 Metro。
- 文件选择与分享由系统界面处理；主动分享给其他应用后，文件离开本应用的控制范围。完整备份是未加密 JSON，可能包含个人内容，请自行妥善保存。
- 禁用 Android 自动备份，避免把本地数据默默交给设备备份服务；用户使用本应用的导出/恢复自行决定备份位置。
- 回收站仅保护备忘录普通删除；永久删除、数据覆盖恢复与系统清数据无法撤销。卸载会移除应用私有数据。同签名覆盖更新保留应用数据。
- 本应用不声称对导出文件加密，也不替你控制其他应用、网盘或操作系统的数据处理。
