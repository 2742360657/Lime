# 数据与隐私

适用于 main 本地版及 v1.2.0 正式发布包；extended/dev 有独立的外部模型/渠道能力，不适用本说明。

- 习惯、待办、备忘录、主题与本地资料保存在应用私有目录 `habit-checkin/data.json`，使用版本化 JSON；无登录、广告、统计 SDK 或远程业务 API。
- 正式 APK 的合并清单不含 INTERNET、SYSTEM_ALERT_WINDOW、旧 READ/WRITE_EXTERNAL_STORAGE 权限；开发调试包需要网络权限连接 Metro，不能据此判断正式包。
- 文件选择与分享由系统界面处理；主动分享给其他应用后，文件离开本应用的控制范围。完整备份是未加密 JSON，可能包含个人内容，请自行妥善保存。
- 禁用 Android 自动备份，避免把本地数据默默交给设备备份服务；用户使用本应用的导出/恢复自行决定备份位置。
- 回收站仅保护备忘录普通删除；永久删除、数据覆盖恢复与系统清数据无法撤销。卸载会移除应用私有数据。
- 本应用不声称对导出文件加密，也不替你控制其他应用、网盘或操作系统的数据处理。
