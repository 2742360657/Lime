# 酸橙 AI：开始使用与数据边界

## 安装

从 README 的 AI Release 下载与你架构匹配的 APK。它与 main 的本地版独立安装，包名 app.lime.personalassistant，使用私密正式签名；旧开发预览的 .dev 包可继续保留，正式包不擅自读取其数据。

AI 测试版后续同签名/同包名版本可覆盖更新，更新前建议导出完整 ZIP。两版数据与备份格式不同，不自动互导；不要卸载或清数据来处理安装冲突。

## 模型与日常操作

1. 助手页点“配置模型”，默认 deepseek-flash；可按 [DeepSeek 官方模型列表](https://api-docs.deepseek.com/api/list-models/) 选择服务支持的名称。
2. 填入自己的 API Key 后点“保存 Key”，模型/人格设置另点“保存设置”。Key 留空不会删除已有 Key；没有 Key 时仅能使用本地功能。
3. 在聊天输入自然语言，或添加图片/文件；示例卡片只填入输入框，不自动发送。普通明确操作可执行，结果保存后可回看来源；高影响操作仍需具体核对。
4. 如需渠道收件，从助手菜单或设置打开微信/QQ，绑定你自己的账号并在前台收件。网络/平台能力决定可用范围，不承诺长期后台或未经验证的历史消息读取。

习惯默认不设目标，只统计周期记录次数；打开目标开关可设 1–9999 次，取消目标不会删除历史。自由记录不会被误判为“已达标”。

## 隐私、备份和验收

模型调用会把本轮输入、选定附件和必要历史发给配置的外部服务，产生费用由你的服务账号决定。不要提交你不希望交给该服务的内容。应用没有宿主 shell、fnOS 或任意 SQL 权限。

设置中导出完整明文 ZIP，含记录、聊天、人格、记忆、来源、附件与提醒等；不含 API Key/渠道凭据和外观设置。请把包保存到可靠位置。恢复不重放助手操作，不自动启用渠道；冲突保留副本。

本次验证使用隔离模拟器和合成数据。真实 Key/真人内容/微信QQ账号未代用户验收；alpha 用于用户自行试用与反馈。
