本批P2-A已建立[命令契约](domain-contracts.md)、固定Jest/Expo测试基础，切换任务与新增打卡消费者；其它编辑/分类/排序仍复用旧事务层，没有声称所有页面已切换。下一步进入P2-B/C的直连SDK兼容、Key/人格、持久化聊天与受限工具；不等待所有渠道或新增日记设计。不要把聊天历史只读视为直连助手已实现。迁移细节见[本地存储说明](local-storage-migration.md)。真机体验继续单独待测。

历史基线的启动条件已校准：无已保存连接时不connect，有旧连接时才自动尝试。当前P1不读取该凭据；原生合成测试确认旧同步表208项队列、新local-only库后续写入/重开均为0。打卡提示也已改为实际事务提交后出现。

本仓库不再计划自建服务器、可选后台、同步系统或服务运维。模型与消息平台云服务是外部API，不是产品自建后台。普通记录独立可用，AI/渠道仍依赖互联网。
