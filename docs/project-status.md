# 当前状态

2026-10-12：1.3.0-alpha.1 为独立安装的 AI 扩展测试版，包名 app.lime.personalassistant；main 本地版另行维护。实际发布入口见 README。

- 核心界面：首页、待办、习惯、备忘录、助手；设置有独立入口，助手提供模型配置引导和仅填入输入框的示例。设置按外观、助手/收件、记录/提醒、备份分组。
- 习惯支持不设目标的自由记录；手动与助手共享命令验证、SQLite 和回执，取消目标保留打卡历史。目标 0 也支持完整备份恢复。
- 助手可处理自然语言/选定附件、查询相关历史、保存日常操作结果与来源；高影响操作仍有具体预览，失败和停止可重试。
- 微信/QQ 保留绑定身份、前台收件、原件和重试机制，当前源码已有收件后处理队列；需要用户自己的模型 Key 和渠道账号。真实服务可用性不能由本地测试代替。
- APK 独立运行，无需 Metro/宿主业务后台；使用私密正式签名发布为 alpha。旧 .dev 预览与正式包为不同应用，数据不自动迁移。
- 已有程序性检查使用合成数据；真实模型准确性、真实微信/QQ和用户手机数据未在本次代为验收。验证范围持续更新 phase-test-ledger，不以历史 APK 证明当前能力。

数据为本机 SQLite；模型与消息 API 在外部。主线本地版 JSON 备份与本分支的完整 ZIP 不是同一格式，不自动互导。
