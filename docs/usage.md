# 使用指南

## 安装与升级

从 [GitHub Releases](https://github.com/2742360657/Lime/releases/latest) 下载 APK。大部分手机使用 arm64-v8a；x86_64 供相应模拟器使用。最低 Android 7.0。

发布包附 SHA256SUMS，Linux/macOS 可运行 `sha256sum 文件.apk`（macOS 用 `shasum -a 256 文件.apk`），与对应行比对。

包名仍是 `com.androidsoftwaredaily.habitcheckin`。v1.2.0 使用新的私密正式签名，因为旧签名材料曾进入公开 Git 历史；旧版 APK 与新版本签名不兼容。

从旧版（含 v1.1.1）迁移：

1. 在旧版设置中导出完整 JSON，保存到应用之外；确认文件确实存在且可读取。
2. 备份未确认前不要卸载、清数据或反复尝试覆盖安装。
3. 确认备份后卸载旧版，再安装 v1.2.0。卸载会删除旧应用私有数据。
4. 在新版设置中导入该 JSON，核对习惯、待办与备忘录；头像可能需重新选择。

以后从 v1.2.0 升级到同签名的新版，先备份，再直接覆盖安装，无需卸载。

当前签名证书 SHA-256：`e4c243856a07e806dea06cd496df1eb9321362e53198e9012d2e36a07b88fd3b`。历史中出现的旧签名和口令不要用于发布。

## 软件更新

v1.3.0 起，设置 → 软件更新显示当前安装版本，支持手动检查与关闭自动检查。自动检查默认开启，仅在打开应用或返回前台时进行，每天最多一次；不影响离线使用，不上传习惯、待办或备忘录。v1.2.x 需先从发布页手动安装一次 v1.3.0，之后即可使用内置更新。

发现新版后可查看说明、稍后处理或“跳过此版本”；跳过只影响自动提示，手动检查仍可找到它。点击“下载更新”后才开始下载，可取消或失败后重试。GitHub 无法访问时可稍后手动检查或打开发布页，不需要清数据。

下载完成会校验文件，点击“安装更新”时再次核对。Android 8+ 首次会打开“允许来自此来源的应用”页面；允许酸橙安装后返回，再点安装更新，并在系统安装器中确认。系统要求手动确认，应用不能静默安装。无需卸载，更新保留原数据；建议定期导出备份。取消系统安装后，可返回设置继续安装；若应用已重启或缓存被回收，重新检查并下载即可。

## 日常使用

- 底部切换今日、待办、习惯、备忘录和设置。顶部显示当前页面名称，“整理”直接进入多选与排序；日期、分组、分类可用列表上方的筛选条或顶部菜单切换。主页依次展示优先处理的待办、可记录的习惯、其他可提前推进的待办，所有未完成任务都能找到。
- 习惯页新建习惯默认不设目标，可只记录次数；打开“设置目标次数”后再填写周期目标。已有习惯的目标保持原样，可在编辑时取消；点按打卡，通过历史查看和补打记录。打卡按当地时间 04:00 切日：凌晨 0:00–3:59 的记录计入前一天，历史分组和达标统计同步按此归属。无需设置提醒权限；本地版不承诺系统通知提醒。自由记录显示实际次数，不计算达标，也不计入首页的目标完成比例。
- 待办列表展示标题、备注摘要和截止时间。设置日期/时间后自动分组，完成可撤销，支持排序和批量整理。点内容编辑，点日期可快速改为今天、明天、3 天后、30 天后或无日期；选项会写明实际日期。列表先按截止日期和具体时间排列，相同截止时间或无日期任务内可手动排序。日期分组在返回前台或页面可见时定期刷新。待办、习惯编辑有未保存修改时，返回或取消会先确认放弃。
- 备忘录标题和分类固定在上方，正文在文字区域内独立滑动，键盘打开后也可浏览、选择和编辑末行。备忘录编辑自动保存，返回或按系统返回键会再确认保存/放弃，也可点右上角“保存”立即写回；可分类、搜索；删除先进入回收站，永久删除后不能恢复。
- 长按条目或点条目菜单可以编辑、查看历史、删除或进入“多选整理”。整理模式在当前页面展开，底部导航保持可见。“多选”模式下点整行选中、全选，使用底部按钮移动或删除；“排序”模式下按住右侧把手拖动，松手即保存，边缘支持自动滚动。待办跨日期分组拖动会先问是“只排序”还是“改时间”，不会悄悄改日期；不同截止时间仍按时间先后排列。按系统返回键或点“完成”退出整理。
- 设置页可换主题、改个人资料和管理归档习惯。

## 备份与恢复

设置 → 数据备份：生成完整 JSON 并打开系统分享。把文件保存到你选择的位置，确认确实保存成功；仅关闭分享面板不代表已有备份。

设置 → 数据恢复：选择可信 JSON，查看内容数量并确认后覆盖当前全部习惯、待办、备忘录、个人资料和主题。导入前另存当前备份；只有实际保存完成后才提示恢复成功。头像文件路径可能无法在另一台手机继续使用，必要时重新选择头像。

应用本身不提供服务器同步。系统卸载、手机损坏或文件丢失时，需要自己的备份恢复；定期把备份放在手机之外。

## 数据异常时

v1.4.0起，保存失败会持续显示“重试保存”，备忘录编辑器也显示保存状态。失败时先保留应用和正在编辑的内容，恢复可写条件后重试；不要清数据或重装。

启动无法读取数据时会进入恢复页，原文件保留，可重新读取或选择自己的JSON备份恢复。若能读取一份完整副本，会提示核对最近修改。恢复前软件在私有目录保留原文件，供后续排障；它不会上传这些文件。

本机完整副本不等于外部备份：卸载、手机丢失或存储损坏仍可能丢数据。仍需定期导出并确认文件已保存到应用之外。

## 色系与外观

设置中的“色系选择”可即时切换十套配色：原有松绿、海蓝、暖棕、柔粉、薄荷、石墨，以及新增玄墨、鸢紫、陶土、橄榄。目前十套均为浅色，缩略预览同时展示页面底色、内容表面与强调色。筛选和整理页签以文字与下划线标明选中，底部导航保留固定入口。
