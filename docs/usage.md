# 使用指南

## 安装与升级

从 [GitHub Releases](https://github.com/2742360657/Lime/releases/latest) 下载 APK。大部分手机使用 arm64-v8a；x86_64 供相应模拟器使用。最低 Android 7.0。

发布包附 SHA256SUMS，Linux/macOS 可运行 `sha256sum 文件.apk`（macOS 用 `shasum -a 256 文件.apk`），与对应行比对。

包名仍是 `com.androidsoftwaredaily.habitcheckin`。v1.2.0 使用新的私密正式签名，因为旧签名材料曾进入公开 Git 历史；旧版 APK 与新版本签名不兼容。

从旧版（含 v1.1.1）迁移：

1. 在旧版设置中导出完整 JSON，保存到应用之外；确认文件确实存在且可读取。
2. 备份未确认前不要卸载、清数据或反复尝试覆盖安装。
3. 确认备份后卸载旧版，再安装 v1.2.0。卸载会删除旧应用私有数据。
4. 在新版设置中导入该 JSON，核对习惯、待办与备忘录；头像可能需重新选择。

以后从 v1.2.0 升级到同签名的新版，先备份，再直接覆盖安装，无需卸载。

当前签名证书 SHA-256：`e4c243856a07e806dea06cd496df1eb9321362e53198e9012d2e36a07b88fd3b`。历史中出现的旧签名和口令不要用于发布。

## 日常使用

- 底部切换今日、待办、习惯、备忘录等主要入口，左侧抽屉提供当前页面的分类和整理操作。
- 习惯页新建习惯默认不设目标，可只记录次数；打开“设置目标次数”后再填写周期目标。已有习惯的目标保持原样，可在编辑时取消；点按打卡，通过历史查看和补打记录。打卡按当地时间 04:00 切日：凌晨 0:00–3:59 的记录计入前一天，历史分组和达标统计同步按此归属。无需设置提醒权限；本地版不承诺系统通知提醒。自由记录显示实际次数，不计算达标，也不计入首页的目标完成比例。
- 待办设置日期/时间后按日期分桶，完成可撤销，支持排序和批量整理。
- 备忘录编辑自动保存，返回或按系统返回键会再确认保存/放弃，也可点右上角“保存”立即写回；可分类、搜索；删除先进入回收站，永久删除后不能恢复。
- 设置页可换主题、改个人资料和管理归档习惯。

## 备份与恢复

设置 → 数据备份：生成完整 JSON 并打开系统分享。把文件保存到你选择的位置，确认确实保存成功；仅关闭分享面板不代表已有备份。

设置 → 数据恢复：选择可信 JSON，确认后覆盖当前全部习惯、待办、备忘录、个人资料和主题。操作无法撤销；导入前另存当前备份。头像文件路径可能无法在另一台手机继续使用，必要时重新选择头像。

应用本身不提供服务器同步。系统卸载、手机损坏或文件丢失时，需要自己的备份恢复；定期把备份放在手机之外。
