# 本机助手契约

更新：2026-10-12。产品依据：[产品定义](../product-scope.md)。业务校验见[命令契约](domain-contracts.md)，原件限制见[材料契约](material-contracts.md)。

固定AI SDK和DeepSeek provider处理流式响应及有限工具循环，Expo fetch直连模型服务。Key只存SecureStore；模型默认deepseek-flash，可选人格原文保存在SQLite，停用时中性表达。人格、材料和查询内容不改变工具权限。

## 自主管理

助手根据自然语言理解明确事实、保存需求、任务和习惯，不再用正则口令授予单次权限。普通新增和调整通过固定业务允许列表执行，结果saved才表示提交；proposal表示具体预览尚未保存；error表示失败。整段备忘录/资料改写、删除、遗忘与取消仍核对。否定、纯提问、假设和第三方经历不能当作用户事实或写入意图，实质对象/时间/数值歧义补问。

语义判断由模型承担；程序限制命令类型、字段、版本、运行中请求和每轮8项提交。测试夹具能验证工具边界与回执，不能证明真实模型一定正确理解每句话或抵抗所有材料诱导。真实模型验收单独记录。

query_memos可搜索标题/正文/分类；query_local_records可搜索标题/正文及类型/标签/时间。read_document取得相关准确版本，captureSource事务保存来源及本轮引用。每轮最多4份/32000字符，附件仅本轮提供的原件。calculate_records使用本轮已读取表格的明确列与单位，有限页不当全量。用户仍可主动选材料，相关历史读取无需逐轮手选。

不将完整数据库自动发模型。材料与读取结果放在user/tool内容，绝不进入system权限指令。带来源的历史请求不自动重发正文/图片及回答，后续需要再查询；来源变化阻止新的提交和预览接受。常用事实/偏好按相关性选择，较早记忆按关键词/游标读取。

## 停止、失败与恢复

全应用共用执行器。停止保留已提交结果；重开将running请求变为interrupted。重试沿用requestId和规范化命令操作ID，持久回执防重复；失败结果允许重试。操作结果卡显示保存状态、具体内容摘要、打开记录及来源入口，页面订阅同一数据库。

忘记记忆清空正文并设置上下文边界，旧聊天仍可查看但不自动参与后续上下文。边界前的请求不能重试读写以复活旧事实。恢复备份的请求是restored只读历史，不能重放权限、建议或业务操作。

当前尚未完成微信/QQ收件后自动排队调用助手；现有渠道与文件仍需交到助手。集中验收包括真实语义、负面/歧义输入、来源诱导、中文输入及真机交互，不用合成SDK测试代替产品验收。
