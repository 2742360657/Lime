# 正式微信前台收件契约

日期：2026-10-10。基线21ce925；范围是已验证官方微信机器人渠道，普通库新增local-only表，独立验证沙箱/凭据不搬运。

设置与助手共用一个收件窗口：获取二维码、手动查询扫码状态（含验证码/区域切换/过期）、解绑、显式读取最多两页/70秒、单件保存或重试。离开窗口或进入后台取消请求；绑定不自动读取，收件不调用模型。二维码仅在内存中，本机编码/显示，不通过第三方二维码服务。

weixin_accounts/weixin_messages继续复用已有事务、本人过滤与无损ID逻辑；新增local_weixin_items是逐部件的收件历史，消息/部件/游标同事务。凭据和媒体下载能力只在独立SecureStore命名空间。更改消息保留已保存原件，撤回/不完整/不支持状态明确显示，不猜测完整内容；下载不完整消息被拒绝。SQL或SecureStore失败不得推进本批游标。

文本和已下载附件显式保存后复用P3材料原件/解析/hash去重。文件错误只标记该项；数据库失败不虚报成功。复制/解析之后、部件回执之前中断，重试通过hash去重恢复。回执使用消息fingerprint与部件revision防止旧下载覆盖新版；保存成功后才释放媒体能力。解除绑定保留收件历史和原件，清除该命名空间凭据及下载能力；旧未保存项提示重新转发。

完整备份格式升为version 2，新增收件历史和材料引用，不包含账号表、游标、原始协议消息表或SecureStore能力。version 1（24类对象）仍可恢复。version 2中的capability_id必须为null；未保存项恢复为只读历史，不能直接重试；已保存原件/文本及来源引用保留，恢复不自动绑定/读取/上传。引用冲突沿用整包保留策略。

新依赖qrcode-generator 2.0.4（MIT，无传递依赖），使用其二维码矩阵，由React Native原有View按整数像素绘制，保留四模块静区；不新增原生二维码SDK。依据[官方协议](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol_zh_CN.md)核对二维码内容/状态和请求头；长时补收、过期附件、合并转发与QQ仍未证实。
