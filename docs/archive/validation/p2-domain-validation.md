## 验收中的修正与续跑

1. 初次Jest配置扫到了.local历史publication快照，并遇到PowerSync common的ESM转换；限制扫描根src/tests、为该库启用转换后通过。Expo preset保持独立；没有伪造原生mock来绕过SQLite校验。
2. 真机首次安装被小米USB安装策略拒绝。用户开启并允许后安装成功；没有卸载旧应用或清除数据。
3. 模拟器UI脚本首次误选首页“待办”标题而不是导航；续跑又发现编辑框填入内容后不再展示占位符。改为优先accessibility导航标识、编辑时匹配当前合成文本，沿同一已创建任务续跑，没有为掩盖失败重复建任务。
4. 后续页面操作、立即重启和SAF导出已执行完成，但导出断言错把内部revision当成可携带备份字段。基础备份设计本就不导出revision。修正断言后，通过`--verify-export`核对已产生的同一实际文件，不再重做页面写入。该模式只报告导出核对，不自行声称重新跑过UI。

因此这里报告的是**分段完成的技术验收**，不是修正后的完整UI脚本首次一遍通过。最终脚本语法通过；修改后的从头完整脚本未另建一套数据重跑。业务源码在这些脚本修正中没有改动。
