# P2-B/C 本机助手阶段报告

日期：2026-10-09。本批实现及关键技术验收完成，手机人工日用验收和正式发布仍待完成。本报告延续[P2-A命令层](p2-domain-validation.md)，不是全功能完成声明。

## 1. 已实现的闭环

- 可选人格：设置内手动选择UTF-8 `.md`/`.txt`/`.markdown`文件，预览后保存或替换；支持停用、移除，默认中性助手。不预置私人人格，正文原样保存。上限128KB、32000字符，保存后不依赖下载目录原文件。
- 手机直接调用DeepSeek：AI SDK Core及官方DeepSeek provider，Expo原生fetch流式，SecureStore保存用户Key；不接产品服务器、Gateway或旧AstrBot。默认`deepseek-flash`，本批支持文本/工具，不以模型视觉能力冒充附件已接通。
- 持久化会话、消息、请求、工具结果、授权与来源；支持生成停止、失败重试及中断恢复。同一执行器串行，最多6轮工具步骤、8次写入，有可清理超时。
- 查询待办、习惯、显式记忆和活动；查询打卡、读取本轮明确选中的日记/备忘录。明确低风险建待办、记忆和唯一活动完成可获得有界授权；其它修改和材料推断用可编辑建议。确定性domain校验目标、版本、来源及原子事务，真实提交后返回回执。
- 跨会话活动承接及关联习惯完成一次打卡；显式记忆查看、更正、忘记。忘记后设置上下文边界，保留可查看历史但不自动重发旧事实。
- AI操作集中在聊天和助手配置。普通日记保存不触发分析，未选材料不读全库，角色虚构与用户事实分开。原服务器聊天仅保留只读历史。

新增7张local-only助手表，与P2-A共21张；保留既有数据，不清库、不卸载应用。Key不写普通数据库、导出、intent或APK。现有基础JSON导出尚不包含新增人格、聊天、记忆、活动和附件；全对象导出恢复在P5补齐。未发送输入当前仅在当前页面内保留，未承诺跨进程草稿恢复。

## 4. 发现的问题与受影响路径复测

1. RN旧取消接口缺少SDK所需的现代AbortSignal；信号单独补丁还造成once监听丢失，缺少全局DOMException导致延迟崩溃。最终使用成熟完整控制器/信号ponyfill，DOMException复用固定RN内置实现，不改Expo fetch。原生短超时、合并取消与SDK工具流复测通过。RN私有导入升级风险写入[技术决策](technology-decisions.md)。
2. DeepSeek拒绝根部没有`type: object`的联合工具schema，合成fixture不能揭示此API校验。补齐根对象类型后真实生产运行时复测提交成功。
3. SDK默认错误日志可能打印包含材料的请求。关闭默认日志回调，改安全错误提示并补回归；不打印Key或完整请求内容。
4. Android键盘遮挡聊天输入栏。改用Android高度避让、明确内容flex及顶部偏移；最终独立preview复测输入/发送和缺Key草稿保留通过。

集中UI测试修正系统语言按钮、选择器启动等待和输入定位后，沿同一合成数据续跑；没有清数据后重新执行一条全新脚本。因此本批记录为分项/分段续跑验收，不声称一遍全绿。后续只复测受变更影响的路径，纯文档不重复收费API或APK构建。
