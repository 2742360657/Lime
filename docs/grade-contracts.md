# 成绩记录与精确查询

2026-10-11。复用本地事务、建议/来源与操作回执；新增local-only `local_grades`，不把文件里的成绩自动存成事实。

课程名/学期明确填写，100分制0到100，分数及正学分最多两位小数，学分可缺失。以整数百分单位保存，用BigInt做求和/乘积/除法，最后四舍五入到两位。相同有效课程/学期不重复录入；修正用已有ID及revision。此范围不推算学校GPA、等级成绩或重修制度。

grade.create/update/trash/restore受严格schema、目标版本及事务回执约束；删除为软删除，恢复不能覆盖已有同课程/学期记录。助手写入用可编辑建议，材料来源按当前明确选择版本校验并保存历史引用；原文不会授权写入，也不自动分析其它备忘录。

界面/助手可按学期精确筛选、课程字面关键词筛选。列表返回matched/returned/complete，不能把前100条当全部；统计一次同事务取完整匹配集，超过1000门明确拒算并要求缩小范围。有任意学分缺失时保留普通平均、拒算整个范围加权平均，注明原因，不静默只算部分。空集合无平均。

完整备份v3纳入成绩及历史来源依赖，兼容v1/v2；恢复不复活模型权限/运行请求。课程备注属于成绩字段，AI显式成绩查询可读；日记/备忘录正文仍需当轮选择授权。

本文件为实现契约；类型/真实SQLite和备份校验集中在本批末，真机界面/真实模型留到统一验收，登记不表示已通过。
